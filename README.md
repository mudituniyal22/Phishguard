# 🛡️ PhishGuard – Phishing Awareness & Detection System

A beginner-friendly, rule-based phishing detection web application built using Flask.

## 🚀 How to Run

1. Install Python (3.8+)
2. Open terminal in project folder
3. Install dependencies:

   pip install -r requirements.txt

4. Run the app:

   python app.py

5. Open browser and go to:

   http://127.0.0.1:5000/
